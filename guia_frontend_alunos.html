🎨 Guia de Design e Frontend: Sistema de Gestão de Laboratório

Bem-vindos à equipe de Frontend e Design! Vocês serão responsáveis por dar vida ao nosso Sistema de Gestão e Agendamento de Laboratório. O objetivo de vocês é criar uma interface que seja bonita, moderna, intuitiva e fácil de usar.

Todo o trabalho de design será feito no Figma, e posteriormente transformaremos esses designs em código HTML/CSS para integrar com o nosso servidor (que está sendo construído em Go).

Abaixo, vocês encontram o detalhamento do que precisa ser desenhado e materiais de apoio para ajudá-los.

📱 1. Detalhamento das Telas (O que desenhar)

O sistema possui diferentes tipos de usuários (Alunos, Professores e Direção). As telas devem refletir as necessidades de cada um. Vocês precisam criar o design das seguintes páginas:

1.1. Autenticação (Login e Cadastro)

  • Propósito: É a porta de entrada do sistema. Deve passar credibilidade e ser super simples.
  • O que precisa ter:
    • Login: Campos de E-mail e Senha, botão "Entrar", link para "Esqueci minha senha" e link "Criar uma conta".
    • Cadastro: Campos para Nome completo, E-mail, Senha, Confirmação de Senha, Matrícula, Telefone e seleção de Perfil (Aluno ou Professor). Botão "Cadastrar".
  • Dica de UI: Pensem em uma página dividida, onde de um lado fica o formulário e do outro uma imagem institucional ou ilustração legal do laboratório.

1.2. Dashboard (Tela Inicial)

  • Propósito: É a primeira tela que o usuário vê ao logar. Deve ser um painel de controle com o resumo do que está acontecendo.
  • O que precisa ter:
    • Menu lateral (Sidebar) ou superior (Navbar) para navegação.
    • Mensagem de boas-vindas ("Olá, [Nome]").
    • Cards de Resumo: Próximos agendamentos do usuário, solicitações pendentes de aprovação e notificações não lidas.
    • Botão de ação rápida: "Novo Agendamento".

1.3. Solicitação de Agendamento (Formulário)

  • Propósito: Onde o professor ou aluno pede para usar o laboratório.
  • O que precisa ter:
    • Seleção de Data (idealmente um mini-calendário).
    • Seleção de Turno (Matutino, Vespertino, Noturno).
    • Horário inicial e Horário final.
    • Seleção de Turma.
    • Campo de texto para Motivo/Observação.
    • Área visual que mostre se o horário escolhido está "Disponível" ou "Ocupado".
    • Botões "Solicitar" e "Cancelar".

1.4. Meus Agendamentos e Histórico

  • Propósito: Permitir que o usuário veja tudo o que ele já agendou ou solicitou.
  • O que precisa ter:
    • Uma tabela ou lista de cards bem organizada.
    • Colunas/Informações: Data, Horário, Turma, Motivo e Status (Pendente, Aprovado, Rejeitado, Cancelado).
    • Pensem em usar "Badges" (etiquetas coloridas) para os status: Verde para Aprovado, Amarelo para Pendente, Vermelho para Rejeitado.

1.5. Agenda / Calendário de Disponibilidade

  • Propósito: Uma visão geral do laboratório, para saber quando ele está livre ou ocupado.
  • O que precisa ter:
    • Uma visualização no formato de calendário (pode ser visão semanal ou mensal).
    • Os horários ocupados devem aparecer como "blocos" no calendário.
    • Filtros para navegar entre as semanas e meses.

1.6. Área da Direção (Administrativo)

  • Propósito: Telas exclusivas para os administradores aprovarem pedidos e gerenciarem o sistema.
  • O que precisa ter:
    • Gestão de Solicitações: Uma lista destacando as solicitações que estão Pendentes. Botões claros de "Aprovar" (verde) e "Rejeitar" (vermelho) para cada linha.
    • Gestão de Usuários: Tabela listando todos os alunos e professores cadastrados, com opções para visualizar detalhes, ativar ou desativar contas.

🎨 2. Como usar o Figma (Fluxo de Trabalho)

O Figma é a ferramenta padrão da indústria para design de interfaces. Vocês não precisam programar nada agora, apenas desenhar.

  1. Criação do Style Guide (Guia de Estilos): Antes de desenhar as telas, criem uma página no Figma só para definir:
    • Cores: Qual o azul principal? Qual o vermelho de erro?
    • Tipografia: Escolham fontes (ex: Inter, Roboto). Definam o tamanho do Título, Texto padrão, etc.
  2. Uso de Componentes: Se vocês criarem um botão, transformem ele em um Componente. Assim, se decidirem mudar a cor do botão depois, muda em todas as telas automaticamente.
  3. Auto Layout: Estudem e usem o Auto Layout do Figma. Ele garante que os elementos fiquem alinhados e espaçados corretamente.
  4. Responsividade: Pensem primeiro em como a tela fica no computador (Desktop), mas não esqueçam de desenhar pelo menos as telas principais no formato de celular (Mobile).

📚 3. Materiais de Estudo Recomendados

Se vocês nunca usaram o Figma ou querem melhorar os conceitos de UI/UX, aqui estão dicas de busca:

  • Dominando o Figma: Pesquisem no YouTube por "Figma para Iniciantes" ou "Figma Tutorial Series". Pesquisem também por "Como usar Auto Layout no Figma".
  • Leis do UX: Acessem lawsofux.com para entender as regras psicológicas por trás de um bom design.
  • Inspiração: Não comecem do zero. Olhem referências em Dribbble.com (pesquisem por "Dashboard") e Mobbin.com.
